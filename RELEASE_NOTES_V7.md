# ZaynClock v7 – Date & Planning Tools

Added six high-demand tools:
- Age Calculator
- Date Calculator
- Date Countdown
- Business Days Calculator
- ISO Week Number Calculator
- Unix Timestamp Converter

Also added:
- Navigation, footer, All Tools and sitemap entries
- A supporting SEO article explaining the date tools
- Canonical metadata, WebApplication schema and breadcrumb schema for each new page

Existing v6.3 features remain included: Islamic Calendar, Sun & Moon, Worldwide Holidays, Interval Timer, Chess Clock fixes, clock styles and the local sound library.
