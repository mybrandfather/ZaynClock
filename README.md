# ZaynClock

A Next.js 15 web application offering a customizable main clock, timers, alarms, world time, planning tools and long-form guides.

## Main clock styles

- Neon 3D seven-segment clock (default for new visitors)
- Orbit Dial clock
- Slide Clock
- Classic digital clock
- Classic analog clock

Users can change the style, theme, accent color, font, time format, seconds visibility and time zone from the settings panel. Preferences are stored locally in the browser.

## Local development

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` before enabling optional services.

## Production build

```bash
npm run build
npm start
```

The project uses Next.js metadata routes:

- `/sitemap.xml` is generated by `app/sitemap.ts`
- `/robots.txt` is generated by `app/robots.ts`

Do not upload old static sitemap or robots files into `public/`, because they would conflict with the metadata routes.

## Canonical domain

The canonical origin is:

```text
https://zaynclock.com
```

For Hostinger Passenger deployments, copy `deploy.htaccess` to `public_html/.htaccess` after confirming the account-specific Passenger paths. It forces HTTP and `www` traffic to the canonical HTTPS origin in one hop.

## Advertising and consent

AdSense loads only when `NEXT_PUBLIC_ADSENSE_ID` is configured. Before enabling advertising, configure the required consent message/CMP in Google AdSense for applicable regions and confirm that the privacy policy matches the live configuration.

## Weather privacy

The weather widget estimates a city from the selected time zone without asking for precise location. Browser geolocation is requested only when a visitor clicks “My location.” Coordinates are sent directly to Open-Meteo services and are not saved by ZaynClock application code.
