# Slide Clock display fix

- Increased each desktop digit viewport from `0.92em` to `1.06em`.
- Increased each mobile digit viewport from `0.88em` to `0.98em`.
- Reduced numeral glyph size from `0.88em` to `0.78em`.
- Added protected horizontal padding inside every numeral cell.
- Prevents wide selectable fonts from clipping curved zeroes and the diagonal
  strokes of 2 and 4 while preserving the vertical rolling effect.
